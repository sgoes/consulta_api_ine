Construtor de URL API INE

Gere URLs personalizados para a API do Instituto Nacional de Estatística de forma intuitiva

Como usar

  1. Carregue o ficheiro JSON com os metadados do indicador
  2. Selecione o indicador desejado da lista
  3. Análise automática: O sistema identifica todas as dimensões disponíveis
  4. Configure as dimensões usando apenas as opções realmente disponíveis
  5. Gere os URLs: Use "Gerar URLs" para múltiplas estratégias ou "Gerar URL Nível Nacional" para dados agregados
  6. Pré-visualize o JSON: Use o botão "Pré-visualizar" para carregar e ver os dados diretamente na página
  7. Copie, descarregue ou abra os URLs e dados gerados conforme necessário
Regras Importantes da API INE
  • Leitura exaustiva: O sistema analisa todo o JSON para identificar dimensões reais
  • Dimensões dinâmicas: Cada indicador tem dimensões específicas e únicas
  • Dropdowns inteligentes: Só mostra opções realmente disponíveis no JSON
  • Caixa de pesquisa: Digite para filtrar valores rapidamente em cada dimensão
  • Apenas Dim1 aceita "T": Apenas a dimensão de período (Dim1) aceita o valor "T" para todos. Outras dimensões devem usar valores específicos
  • Use códigos específicos: Para Dim2, Dim3, etc., sempre selecione valores específicos no dropdown
  • Endpoints diferentes: pindica.jsp para dados, pindicaNoLevel.jsp para níveis geográficos
  • Termina sempre com &lang=PT: Todos os URLs gerados terminam com este parâmetro
  • Botão "Nível Nacional": Gera automaticamente URL com todas as dimensões em lvl@1 usando pindicaNoLevel.jsp
  • Pré-visualização com proxy: Tenta carregar JSON usando proxies CORS, mas pode falhar devido a restrições de segurança
  • Alternativa: Nova aba: Se a pré-visualização falhar, use "Abrir numa Nova Aba" para ver o JSON diretamente na API
  • Metadados seguros: O URL de metadados (indicaMeta.jsp) sempre funciona
